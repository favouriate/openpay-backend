# OpenPay Backend

Production-oriented backend API for the OpenPay fintech portfolio application.

## Planned Stack

- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Prisma ORM
- REST API
- Swagger / OpenAPI

## Product Scope

OpenPay is a Nigeria-focused, NGN-only fintech portfolio application.

The backend will support:

- user authentication
- customer profiles
- NGN accounts and balances
- Nigerian financial institution directory
- internal and external transfer modelling
- transfer fees
- transaction history
- idempotent money-moving operations
- secure refresh-token sessions
